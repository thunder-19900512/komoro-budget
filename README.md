# まるっと予算ナビ@小諸（小諸市 令和8年度予算・β版・非公式）

小諸市の令和8年度一般会計当初予算（237億円）が、どこから入り何に使われるかを図で見られる静的サイトです。

**小諸市の公式サイトではありません。** 小諸市が公開している資料をもとに個人が作成した非公式のページです。

## 中身

| パス | 内容 |
|---|---|
| `index.html` | ページ本体。データを埋め込んであるので、ダブルクリックでも開けます |
| `vendor/d3.min.js` | 描画ライブラリ d3 v7.9.0（ISC ライセンス、`vendor/d3-LICENSE`） |
| `data/*.json`, `data/*.csv` | ページで使っているデータ（単位：千円）。CSV は Excel でそのまま開けます |
| `tools/` | 予算書PDFからデータを作ったときのスクリプト。`build_compare.py` は総務省のxlsxから比較データを作り、`index.html` に埋め込む |
| `docs/hikaku.md` | 「似た市と比べる」の比較先の選び方 |

### データ

| ファイル | 内容 | 出典 |
|---|---|---|
| `rev_kan` | 歳入の款別金額と前年度額 | 当初予算書 事項別明細書 総括 |
| `rev_kou` | 歳入の項別金額 | 当初予算書 第1表 |
| `rev_kikin` | 基金繰入金の内訳 | 当初予算書 歳入事項別明細書 |
| `exp_kan` | 歳出の款別金額・前年度額・財源内訳（国県支出金・地方債・その他・一般財源） | 当初予算書 事項別明細書 総括 |
| `exp_kou` | 歳出の項別金額 | 当初予算書 第1表 |
| `projects` | 説明欄で「◎」の付いた事業 249件（合計は一般会計総額と一致） | 当初予算書 歳出事項別明細書 |
| `population` | 人口（令和8年4月1日） | 小諸市 区別世帯人口表（住民基本台帳） |
| `compare` | 小諸市・近隣6市町・似た4市の決算指標（令和2〜6年度、1人あたりは円）と、同じ類似団体区分の中央値 | 総務省「市町村別決算状況調」、「類似団体別市町村財政指数表」、「住民基本台帳年齢階級別人口」 |

収入から財源区分への流れの一部は推計です（ページの「説明と出典」タブに方法を記載）。

比較データを作り直すときは `python3 tools/build_compare.py`（openpyxl が必要。総務省のxlsxは `tools/.cache/` に保存されます）。

## デザイン

チームみらいのデザインシステム（Webアプリ向け v0.3、党内ハンドブック `04-development/design-system`）のトークンに合わせています。単一HTML・Tailwindなしの構成のため、トークン名と意味だけを揃えています（SKILL.md §13 の例外と同じ扱い）。

- フォント：Noto Sans JP（Google Fonts から読み込み）
- 色：プライマリ `#2AA693`、背景は marumie と同じ薄ティールのグラデーション、カードは白・角丸24px・影なし
- タブの選択中表示：ミントのグラデーション＋黒1pxボーダーのピル
- サンキー図の色：一般財源＝ティール、国・県の補助金など＝スレート、市債＝赤（marumie の支出色）、その他の特定財源＝グレー
