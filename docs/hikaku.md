# 「似た市と比べる」の比較先の選び方

ページの「似た市と比べる」で、小諸市と比べている4市（須坂市・東根市・小美玉市・かすみがうら市）を選んだ手順です。

## 1. 総務省の類似団体区分

- 総務省は、全国の市町村を「人口」と「産業構造」でグループ（類型）に分けています。それぞれの財政を比べる物差しとして、「類似団体別市町村財政指数表」を毎年公表しています。
- 令和6年度の指数表で、小諸市は **都市Ⅰ－１** に入っています。
  - 「Ⅰ」は人口5万人未満です。
  - 「－１」は、第2次・第3次産業の就業者が90％未満で、第3次産業が55％以上のグループです。
  - 割合は令和2年国勢調査によるもので、分母には「分類不能の産業」を含みます。
- 都市Ⅰ－１は全国に132市あります。このうち124市が、総務省の平均の計算に使われています。
- 出典：[令和6年度 類似団体別市町村財政指数表](https://www.soumu.go.jp/iken/ruiji/ruijiR06.html)（作成方法、都道府県別団体名一覧表）

## 2. 絞り込みの順番

同じ区分の中から、次の順で絞りました。

1. **海に面していない（内陸にある）**
   - 海沿いの市は、産業（漁業・港）や災害の前提が違うため、除きました。
2. **人口と面積が近い**
   - 人口はおおむね3万〜5万人。
   - 面積は250km²以下（小諸市は98.55km²）。
   - この区分には、合併で面積が数百km²になった市が多くあります。面積が大きく違うと、道路や学校の配置の前提が変わるため、除きました。
3. **財政の強さと人口の動きが近い**
   - 財政力指数は0.55〜0.62（小諸市は0.58）。
   - 人口の減り方が比較的ゆるい。

## 3. 4市の違い

- **須坂市・東根市**：盆地や山地を抱える、寒い内陸の市。地形も小諸市に近い。
- **小美玉市・かすみがうら市**：数字は近いものの、関東平野の平らな土地にある。道路・除雪・農地など、地形に左右される費用は割り引いて見る必要がある。
- 高原の観光地を抱え、面積が100km²前後という点まで小諸市に近い市は、同じ区分の中に見つかりませんでした。

## 4. 注意

- 類似団体区分は、令和2年国勢調査をもとにしています。令和7年国勢調査の結果で、区分が変わる可能性があります。
- 比較の数字は、団体ごとの事情で大きく変わります。たとえば、広域連合に任せている仕事、学校の建て替えの時期、観光地の有無などです。数字の大小だけで、良い・悪いは決まりません。
